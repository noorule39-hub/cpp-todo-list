C++ To-Do List Application

Simple command-line to-do list manager with file saving.

#Features
- Add/delete tasks
- Mark tasks complete
- Tasks save to file automatically

## How to Compile
bash
g++ -std=c++11 main.cpp -o todo


# How to Run
bash
./todo

# Skills
- STL vectors and strings
- File I/O (fstream)
- Classes and OOP
